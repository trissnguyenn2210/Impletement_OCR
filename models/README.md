# Model provenance

`PP-DocLayout_plus-L_pretrained.pdparams` was downloaded from the official
PaddleX model store:

https://paddle-model-ecology.bj.bcebos.com/paddlex/official_pretrained_model/PP-DocLayout_plus-L_pretrained.pdparams

It is a training checkpoint for fine-tuning, not the final inference directory.
PaddleX creates the inference files after training/export.

Large model files are tracked with Git LFS.
